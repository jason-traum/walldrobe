What the prototype demonstrates

Kept art follows arrangement changes. Art swaps preserve frame positions. Removing a frame returns to Layout. Undo reverses wall changes. Versions groups consecutive edits; All changes retains each one. Restoring an earlier version creates a new branch. The three arrangements and eight prints are illustrative fixtures.
